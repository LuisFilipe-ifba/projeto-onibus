# Onibus-Plus

Projeto web desenvolvido com React para gerenciamento de informações relacionadas a ônibus e usuários.

## Estrutura das páginas

```text
App
├── Header
├── Rotas
│   ├── /            -> Home
│   │                  └── Main
│   ├── /login       -> Login
│   │                  └── LoginForm
│   └── /usuarios    -> Usuarios
│                      └── UserTable
└── Footer
```

## Estrutura do projeto

```text
src/
├── components/
│   ├── Header.jsx
│   ├── Navbar.jsx
│   ├── Main.jsx
│   ├── LoginForm.jsx
│   ├── UserTable.jsx
│   └── Footer.jsx
├── pages/
│   ├── Home.jsx
│   ├── Login.jsx
│   └── Usuarios.jsx
├── css/
│   └── style.css
├── App.js
├── App.css
└── index.js
```

## Tecnologias utilizadas

- React
- React Router
- JavaScript
- CSS

## Como executar

```bash
npm install
npm start
```
